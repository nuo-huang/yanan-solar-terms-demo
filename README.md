# 二十四节气 · 洛川物候观察（测试站）

访问：https://nuo-huang.github.io/yanan-solar-terms-demo/

本仓库只存放编译后的网页成品与依赖许可证，不存放开发工程。运行版本：`f8f5c48`（2026-11-24部署）。

## 演示边界

园区、地形、树木、作物物候、天气与季节变化均为讲解用程序化示意，并非真实园区数字复原或洛川逐年实测。50%节气天气变化属于交互规则，不是实测发生概率。历史40年分析尚未接入长期观测。

## 查看建议

使用较新的桌面 Edge / Chrome，开启浏览器硬件加速；默认均衡画质，可观察四季代表节气并自由漫游。性能取决于访问设备显卡，手机及集显可能较慢。首次载入需等待场景生成。
